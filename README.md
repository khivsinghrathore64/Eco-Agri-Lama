# 🎃 Eco Agri Lama: Dark Harvest

An AI-powered agricultural companion built with a spooky "Dark Harvest" theme for the Kiroween hackathon. Features high-polish UI and functional logic for field management, AI remedy consultations, cyclical crop rotation, and regenerative soil carbon tracking.

## 🦇 Features
- **👻 Field Telemetry**: Real-time soil moisture and ambient temperature tracking.
- **🔮 Oracle AI Remedy Chat**: Offline-capable diagnostic tool for organic pest and disease solutions.
- **🔄 Crop Rotation Board**: Cyclic bed management across Leafy Greens, Fruiting Crops, Root Vegetables, and Legumes.
- **🌱 Soil Carbon Ledger**: Regenerative agriculture tracker calculating total aggregated kg CO₂e offset.

## 🛠️ Stack
- React 18, Vite, Tailwind CSS, Base44 SDK.
